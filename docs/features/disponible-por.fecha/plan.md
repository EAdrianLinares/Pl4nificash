# Plan de implementación

## 1. Backend

- Revisar endpoint de movimientos.
- Revisar servicio que calcula el disponible.
- Filtrar movimientos por fecha <= fecha actual.
- Calcular ingresos.
- Calcular gastos.
- Retornar disponible acumulado.

## 2. Frontend

- Actualizar consumo del endpoint.
- Actualizar tarjeta de disponible.
- Verificar formato monetario.

## 3. Pruebas

- Sin movimientos.
- Solo ingresos.
- Solo gastos.
- Ingresos y gastos.
- Movimientos futuros.
- Movimientos de fechas anteriores.
