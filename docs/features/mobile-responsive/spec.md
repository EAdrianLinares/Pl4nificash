# Mejora de visualización móvil

## Objetivo

Adaptar la aplicación para que sea usable y visualmente
correcta en dispositivos móviles.

## Requisitos

- La aplicación debe funcionar correctamente desde 320px
  de ancho en adelante.
- No debe existir scroll horizontal.
- Las tablas deben adaptarse a pantallas pequeñas.
- Los formularios deben ocupar el ancho disponible.
- Los botones deben ser fácilmente seleccionables con el dedo.
- Los elementos del dashboard deben reorganizarse verticalmente.
- Los textos no deben desbordar sus contenedores.
- Los modales deben adaptarse al ancho disponible.
- La navegación debe ser usable desde dispositivos móviles.

## Breakpoints

Mobile:
< 576px

Tablet:
576px - 991px

Desktop:
>= 992px
